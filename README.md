# Opel Узбекистан — сайт официального дилера

Статический сайт по образцу дилерских сайтов Opel (структура, как у `opel-kz.com`),
адаптированный для рынка Узбекистана: цены в сумах, города и дилерские центры Узбекистана,
переключение языков **RU / UZ**, кредитный калькулятор и формы заявок.

Сборка не требует зависимостей — только Node.js 18+ (используется для генерации HTML).
Готовый сайт — обычные статические файлы, их можно положить на любой хостинг.

---

## Быстрый старт

```bash
node tools/build.mjs          # собрать HTML из src/ и data/
python3 -m http.server 8099   # открыть http://127.0.0.1:8099
```

Или через npm-скрипты: `npm run build`, `npm run serve`, `npm run check`.

> **Важно:** HTML-файлы в корне (`index.html`, `models/*.html` и т. д.) — **сгенерированные**.
> Их нельзя править напрямую: изменения затрутся при следующей сборке.
> Правьте `src/` и `data/models.json`, затем пересоберите.

## Структура

```
data/models.json          модели, комплектации, цены, дилерские центры (единственный источник данных)
src/layout.html           общий каркас страницы (<head>, подключение стилей и скриптов)
src/partials/             шапка, подвал, форма заявки, кредитный калькулятор, мобильная панель
src/pages/*.html          содержимое страниц (фрагмент + заголовок <!--meta {...}-->)
src/templates/model.html  шаблон страницы модели
tools/build.mjs           сборка: src + data → HTML, sitemap.xml, robots.txt
tools/make-cars.mjs       генерация SVG-иллюстраций автомобилей (заглушки)
tools/check-i18n.mjs      проверка: у каждого ключа есть узбекский перевод
assets/css/style.css      стили
assets/js/i18n.js         узбекский словарь (русский текст берётся из самой разметки)
assets/js/main.js         меню, слайдер, калькулятор, валидация форм, переключение языка
_legacy/mogo/             старый шаблон, лежавший в репозитории до этой работы
```

## Как менять контент

**Модели, комплектации, цены, дилеры** — `data/models.json`. Каждое текстовое поле
двуязычное: `{"ru": "...", "uz": "..."}`. После правки: `node tools/build.mjs`.

**Тексты страниц** — `src/pages/*.html`. Русский текст пишется прямо в разметке,
у элемента указывается ключ `data-i18n="…"`, а узбекский перевод добавляется в
`assets/js/i18n.js`. Проверка полноты переводов:

```bash
node tools/build.mjs && node tools/check-i18n.mjs
```

**Новая страница** — создайте `src/pages/имя.html`, начните файл со строки

```html
<!--meta {"path":"имя.html","nav":"about","title":"…","desc":"…","ogImage":"hero-grandland.svg","actionbar":true} -->
```

и добавьте ссылку в `src/partials/header.html` / `footer.html`.

## Что обязательно заменить перед публикацией

- [ ] **Фотографии автомобилей.** В `assets/img/` сейчас SVG-заглушки, сгенерированные
      `tools/make-cars.mjs`. Замените файлы с теми же именами на официальные фотографии
      (карточки — 640×300, hero — 1600×900) или поправьте пути в разметке.
- [ ] **Логотип.** `assets/img/logo-mark.svg` и `favicon.svg` — нейтральные заглушки.
      Используйте официальные брендовые файлы, полученные у дистрибьютора.
- [ ] **Цены и комплектации.** Значения в `data/models.json` приведены как пример
      и не являются реальным прайс-листом. То же касается прайса на сервис в `src/pages/service.html`.
- [ ] **Контакты.** Телефон `+998 (71) 200-00-00`, почта `info@opel-uz.example`,
      адреса с «000» — заглушки. Правятся в `data/models.json` (дилеры) и в
      `src/partials/header.html`, `src/partials/footer.html`, `src/pages/dealers.html`.
- [ ] **Домен.** Канонические ссылки, Open Graph и `sitemap.xml` собираются из переменной
      `SITE_URL`: `SITE_URL=https://ваш-домен.uz node tools/build.mjs`.
- [ ] **Карта** на `dealers.html` — вместо блока-заглушки вставьте код Яндекс.Карт или Google Maps.
- [ ] **Юридические тексты** — `privacy.html` и дисклеймер в подвале проверяются юристом,
      добавляются реквизиты оператора персональных данных.
- [ ] **Аналитика** (Яндекс.Метрика / Google Analytics) — подключается в `src/layout.html`.

## Формы заявок

Формы (заявка, тест-драйв, запись на сервис, вопрос) проходят клиентскую валидацию
(имя, телефон в формате `+998 (XX) XXX-XX-XX`, согласие на обработку данных) и по умолчанию
**никуда не отправляются** — данные пишутся в консоль браузера.

Чтобы подключить бэкенд, задайте адрес перед `main.js` в `src/layout.html`:

```html
<script>window.OPEL_LEAD_ENDPOINT = "https://api.ваш-домен.uz/leads";</script>
```

Отправляется `POST` с JSON:

```json
{
  "form_kind": "testdrive",
  "name": "Азиз",
  "phone": "+998 (90) 123-45-67",
  "model": "grandland",
  "dealer": "0",
  "comment": "",
  "consent": "on",
  "page": "/test-drive.html",
  "lang": "ru"
}
```

Дальше заявку можно класть в CRM, отправлять на почту или в Telegram-бот
(`https://api.telegram.org/bot<token>/sendMessage`) — токен должен оставаться на сервере,
в коде сайта его размещать нельзя.

## Двуязычность

Русский — исходный язык, его строки лежат в разметке. `assets/js/main.js` запоминает их при
загрузке, а `assets/js/i18n.js` содержит только узбекские переводы (ключи `data-i18n`),
плюс небольшой русский блок для строк, которых нет в разметке (ошибки валидации).
Выбранный язык сохраняется в `localStorage`, цены и слово «сум/so'm» форматируются на лету.

Для контента из `data/models.json` переводы подставляются в атрибуты
`data-i18n-ru` / `data-i18n-uz` прямо при сборке.

## Деплой

Сайт статический, серверная часть не нужна.

- **GitHub Pages:** Settings → Pages → Deploy from branch, папка `/ (root)`.
- **Любой хостинг / CDN:** загрузите содержимое репозитория (кроме `src/`, `tools/`, `data/`,
  `_legacy/` — они нужны только для сборки).
- Перед загрузкой соберите сайт с реальным доменом:
  `SITE_URL=https://ваш-домен.uz node tools/build.mjs`.

## Проверки

```bash
node tools/build.mjs        # падает, если в шаблонах остались незаполненные плейсхолдеры
node tools/check-i18n.mjs   # падает, если у ключа нет узбекского перевода
```

Вёрстка проверялась в Chromium на ширинах 1440 и 390 px: консоль без ошибок,
горизонтальной прокрутки нет, работают слайдер, калькулятор, фильтр моделей,
табы комплектаций, аккордеон, мобильное меню и валидация форм.

## Правовое замечание

Opel и связанные обозначения — товарные знаки их правообладателей. Использовать бренд
в оформлении сайта и называть себя официальным дилером/дистрибьютором можно только при
наличии соответствующего соглашения. Цены и комплектации на сайте сопровождаются пометкой,
что информация не является публичной офертой.
